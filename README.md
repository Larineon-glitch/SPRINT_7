Проект Sprint_7: Тестирование API Яндекс Самокат
- Описание проекта:
Проект содержит автоматизированные тесты для API учебного сервиса Яндекс Самокат (https://qa-scooter.praktikum-services.ru/).

- Что покрыто тестами:
1. Базовое
   - Создание курьера
   - Логин курьера
   - Создание заказа  
   - Получение списка заказов
2. Дополнительное
   - Удаление курьера
   - Принятие заказа
   - Получение заказа по его номеру

Технологии и инструменты
- Python 3.9 - язык программирования
- Srequests - для отправки HTTP-запросов
- pytest - фреймворк для запуска тестов
- Allure - для генерации красивых отчетов

Обработка известных проблем API
В тестах учтены известные проблемы API:
- Сервер возвращает 500 вместо 400 в некоторых случаях
- Тексты ошибок могут незначительно отличаться
